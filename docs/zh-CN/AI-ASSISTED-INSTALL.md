# 让 AI 助手帮你安装并开始使用 SintBot

[English](../AI-ASSISTED-INSTALL.md) · 简体中文

AI 助手只有能操作 **SintBot 实际运行那台电脑的本机终端**，才能直接安装。纯聊天或云端 Shell 不能把软件装到你的 Mac。若助手连不上本机终端，就在目标电脑的「终端」里运行安装命令，再让助手继续核对。

一键安装支持 macOS 和 Linux（Linux 为实验性支持）；Windows 请按[手动步骤](./install.md#windows)。

## 最短流程

1. **先检查。** 核对目标系统、Node 版本、SintBot 版本和服务状态；不要读取或打印配置、凭据。
2. **选对路径。** 新装先把官方安装脚本下载到临时文件、检查并做无修改预览；获准后执行同一份文件。升级只更新程序包，不重跑模型配置或试跑。重启正在运行的服务可能会向已接入的群播报升级。
3. **一次确认。** 改动前用一条简短摘要列清：是否要用 Homebrew 安装 / 升级 Node、缺少时安装必需的 Claude Code CLI、模型选择及试跑可能产生的费用、是否安装 / 重启后台服务。只问还没确定的选项。获得批准后，助手按已选方案处理安装器重复出现的相同选项，不再重复打断；若出现未说明的新改动，先停下询问。
4. **在本机执行。** 使用目标电脑的交互终端。账号登录由用户本人完成；API key 只由用户在 SintBot 本机遮罩提示中输入。不要把凭据复制进聊天或助手记录，也不要用 `sudo`。
5. **完成首次使用。** 核对版本、体检和服务状态。在控制台按「开始使用」完成：确认模型可用、按需接聊天平台、把一个群绑定到一个项目目录，再发一条只读测试消息。暂时不接平台，也能先在「试跑」里验证模型。

如果还要创建或审批聊天平台应用，助手按对应的[平台接入说明](./platforms/)逐步引导；凭据由用户直接填在本机控制台。每次只问下一步必需的信息，不重复索要已经提供的内容。

## 助手没有本机终端时

不要在另一台电脑或云端 Shell 上真实安装。可以做不改动系统的 `--dry-run` 预览；没有交互终端时，真实安装若缺少 Node 22+ 会停止，若已有 Node 也可能只安装程序包并提示配置未完成。让用户在目标电脑运行[一键安装](./install.md#一键安装)，再由助手继续核对。

## 可直接发给 AI 助手

```text
请帮我在这台电脑安装或升级 SintBot，并完成首次使用。只能操作它实际运行这台电脑的本机终端。先核对系统、Node 版本、SintBot 版本和服务状态；不要读取配置或凭据。

新装先把官方安装脚本下载到临时文件、检查并运行无修改预览；获准后执行同一份文件。升级只更新程序包，不重跑模型配置或试跑。改动前用一条简短摘要说明 Node / Claude Code 安装、模型选择与试跑可能产生的费用、后台服务安装或重启（含群播报），一次问清需要我决定的选项。获得我的批准后，按已选内容处理重复的安装器确认，不要再问一遍；若出现新的改动要求就先停下。

只用目标电脑的交互终端。我会自行登录，并在本机遮罩提示中输入 API key；不要把凭据放进聊天。不要用 sudo 或重置现有数据。安装后核对版本、体检和服务状态，再带我完成控制台「开始使用」：可以先在「试跑」验证模型；需要群聊时再接平台、绑一个群到一个项目目录，并发一条只读测试。每次只问下一项必需选择；遇错先停下说明原因。
```

## 给 AI agent 派清楚任务

写代码时，说明目标、验收结果和限制。例如：

```text
目标：……
完成标准：……
限制：……

先看项目说明和当前状态。信息足够就直接执行；只有缺少的信息会阻塞工作时才问我。完成后简要列出改动、检查结果和未完成项。
```
