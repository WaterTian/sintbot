# 备选风格档（不进默认风格库）

这一层的档**不会出现在 `sbot design styles` 里** —— `listStyles` 只扫上一级目录，
子目录天然不被收录。放在这里的都是**质量合格但位置太挤**的风格：库里已经有一个
离它很近的了，两个并排出候选图时用户分不出差别，反而让选择变难。

要启用某一个：`mv extra/<slug>.md ../` 即可，代码零改动。

## 为什么砍这九个（判据是「彼此够不够远」，不是「好不好」）

| 档 | 与谁太近 |
|---|---|
| `paris-couture` 巴黎高定 | ≈ 静奢（都是浅底近黑字、0 圆角 0 描边，靠强调色与间距单位区分） |
| `nordic-material` 北欧物性 | ≈ 杂志编辑 + 圆融亲和的交集 |
| `wa-shikimen` 和・色面 | 与新中式方向相反（色面平涂 vs 线描、灰调伝統色 vs 暖宣纸），但对用户就是「两个东方风格」 |
| `constructivism` 构成主义 | ≈ 几何构成（纪律其实相反：斜轴/动势 vs 正交/静态，但视觉相近） |
| `tropical-modern` 热带现代 | 撞构成主义 —— `muted` 是**同一个 hex** `#6E6A63`，红只差 2 |
| `new-wave` 新浪潮 | 最难稳定复现：它要求「精确计算的失序」，AI 极易做成随机旋转 |
| `y2k-chrome` 千禧未来 | ≈ 酸性荧光（都是高能 + 铬/荧光；分界是「光打在表面」vs「光穿过物体」） |
| `ulm-functional` 乌尔姆功能 | 撞精密仪表 —— 同 `suits`、同 4px unit、圆角 2/4 对 4/6 |
| `neo-brutalism` 新粗野主义 | 2022-2023 被组件库大量复制，已经是廉价感的信号；「吵闹」那一格由酸性荧光填 |

内容本身没有问题：实测色值、真实参照、文化误用清单都在，捡回来即可用。
